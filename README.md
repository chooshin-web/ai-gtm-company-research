# AI GTM Company Research Tool

A Python automation project that generates structured B2B company research reports from a sample dataset.

## Features

- Research company information
- Identify business pain points
- Generate outreach recommendations
- Export reports as text files
- Simple command-line interface

## Technologies

- Python 3
- Dictionaries
- File Handling
- Automation

## How to Run

1. Clone the repository.

```bash
git clone https://github.com/chooshin-web/ai-gtm-company-research.git
```

2. Install requirements.

```bash
pip install -r requirements.txt
```

3. Run the program.

```bash
python main.py
```

## Example

Input:

```
OpenAI
```

Output:

- Company information
- Business pain points
- Outreach recommendations
- Report saved inside the **outputs/** folder
