# AI GTM Company Research Tool

A Python automation project that generates structured B2B company research reports from a sample dataset.

## Features

- Research company information
- Identify business pain points
- Generate outreach recommendations
- Export reports as text files
- Simple command-line interface

## Technologies

- Python 3
- File Handling
- Dictionaries
- Automation

## Example

```
Enter a company name:

OpenAI
```

The program generates a structured report and saves it inside the `outputs` folder.

## Folder Structure

```
main.py
outputs/
docs/
screenshots/
```
