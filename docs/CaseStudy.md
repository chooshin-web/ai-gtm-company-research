# Case Study
## Project Overview

This project demonstrates a simple AI-assisted B2B company research automation tool built using Python.

The application accepts a company name, searches a structured dataset, generates a formatted company research report, and saves the report as a text file.

---

## Problem

Sales teams often spend time gathering basic company information before writing outreach emails.

This project automates the first step by producing a structured company research summary.

---

## Solution

The application:

- Accepts a company name from the command line
- Searches a structured company database
- Generates a formatted B2B research report
- Displays the report in the terminal
- Saves the report automatically to the outputs folder

---

## Technologies Used

- Python 3
- Dictionaries
- File Handling
- Command Line Interface (CLI)

---

## Results

The application successfully generated reports for sample companies including:

- OpenAI
- HubSpot
- Stripe

Each report includes:

- Industry
- Website
- Business pain points
- Outreach recommendations
